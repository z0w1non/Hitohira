# テストカバレッジマトリクス

| 仕様章 | 単体で確認する動作 | ブラウザー操作で確認する動作 |
|---|---|---|
| 画面構成と初期表示 | 静的UIのID一意性、アイコンボタンの操作名、起動時の本文選択と後続処理、通知の自動閉鎖と再通知 | HTML起動、ヘルプの開閉、設定・目次ドロワーの切替、FirefoxでのHTML起動・既定本文の表示と実キー入力による設定ドロワーの開閉 |
| 本文表示・文字組み | 台詞・ルビと許可リンクの変換、未許可リンクの除外、表・リスト・コードブロックの順序と空行境界、長い漢字列・空白を含む本文の変換 | 本文幅・書字方向・書体の変更、HTML取り込み後の本文DOMとサニタイズ済み属性 |
| テーマ・配色 | Wake Lockの取得・解放・再取得、非対応と取得失敗、画像の読み込み状態に応じた個別色・自動配色の反映 | テーマ切り替え時の個別色の維持と既定色の更新、明暗のPNGによる自動配色と解除後の個別色復元 |
| 初期設定 | 起動処理が採用する既定値、部分保存の補完、破損時のフォールバック | 新規プロファイルの初期値と計算済みスタイル、文字組み・ルビ・本文パネルの変更と初期化、進捗表示の切替 |
| インポート | Markdown構文と見出し上限、UTF-8/UTF-16と復号失敗、本文・位置・元バイト列の更新、非対応ファイルの通知、画像寸法検証とURL解放、背景の表示・位置・動画再生、保存容量超過の通知と既存本文・元ファイルの維持 | ファイル選択、本文・画像のドロップ、背景画像・動画のマウスドラッグと移動範囲、画像の位置復元とリセット、タッチ操作の終了・中断と縮小図、移動中の動画再生 |
| エクスポートと元ファイルのエクスポート | 元Blobと拡張子の維持、SHA-256による命名、API非対応時の拒否、利用者向け通知とエラーログ | 個別行の追加・削除・置き換え、新規プロファイルでのHTML単体起動と個別出力のバイト照合、失敗時の案内・ログ・自動閉鎖と出力ファイルの非生成、容量制御下での書き出し計測と埋め込みデータのサイズ照合 |
| エクスポートHTML内のデータと初期化 | Base64のチャンク境界、バイト列・MIMEの復元、不正ペイロードの拒否、初期化と個別削除の保存失敗・再試行、初期化可否の読書位置除外、エクスポートHTML内蔵データの保持 | 通常版の設定初期化、エクスポートHTMLの初期化・再読み込み後の復元、内蔵JSON・Base64の破損時と画像・動画のデコード失敗時の通知と本文表示 |
| 目次・読書進捗・読書位置 | 進捗の軸と上下限、書字方向変更時のブロック優先・進捗フォールバック、目次項目の生成・選択・強調 | 目次ドロワーの開閉、進捗表示切替、複数章の本文の再読み込みと書字方向切り替え前後の読書位置 |
| ページ送り・テキスト選択・カーソル | 書字方向別の移動量、Shift+Space、対象外の方向キー、縦書きのホイール移動、ダブルクリック時の選択維持とページ送り抑止 | F1・S・O・Escape、横書き・縦書きの長押し移動とキー解放後の停止、ダブルクリックの単語選択、本文と余白のカーソル |
| 保存データとストレージ | 読書位置と全設定の復元、設定の部分保存・破損、IndexedDBの容量超過による中断と旧レコードの保持、削除と再保存 | 再起動後の背景画像・本文元ファイルの復元、通常版の設定・本文・読書位置・元ファイルの一括初期化、容量を制限したオリジンでの保存拒否 |

単体テストは各ケースで新しいVMと状態を用意する。ブラウザーAPIは必要箇所で代替する。読書位置の文書キーはテストで供給し、キーを使った保存・復元を確認する。ブラウザー操作欄はスイートが実装している対象を示し、実行できたかどうかは実行結果で確認する。

ブラウザー操作テストは既定の動的TCPポートと、`NOVEL_VIEWER_CDP_PIPE=1`で指定するパイプ接続で同じ機能ケースを実行する。CDP接続に失敗した場合は、接続方式、起動引数、対象URL、終了コード、標準エラーを実行ログで確認する。
