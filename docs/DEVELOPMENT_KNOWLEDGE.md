# 開発・検証で得た知見

実装や検証で得られた、後続作業に再利用できる知見を記録する。未解決の作業・判断待ちは[課題表](./ISSUES.md)、予定と進捗は[開発計画](./PLANS.md)で管理する。

## 記録項目

| 列 | 記録する内容 |
|---|---|
| ID | 知見を一意に参照する番号。[共通採番規則](./IDENTIFIERS.md)に従い、`KNW-001`から順に付与する。 |
| 確認日 | 確認を行った日付。 |
| 分類・対象 | ブラウザー、保存、UI、ビルド、環境などの対象。 |
| 知見 | 確認された事実または再利用可能な結論。仮説は事実と分けて明記する。 |
| 根拠・確認方法 | 再現に使った入力・操作・コマンドと観測結果。可能なら成功数や具体値を記録する。 |
| 適用範囲 | どの実装・環境・テストに適用できるか。 |
| 制約・注意 | 環境依存、未確認範囲、誤用を避ける条件。 |
| 再確認条件 | どの変更や環境変化があれば知見を再検証するか。該当しない場合は「特になし」。 |
| 関連資料 | 実装、仕様、テスト、課題などのリポジトリ内リンク。 |
