# Hitohira

A standalone novel viewer for reading from a single HTML file. It supports TXT, Markdown, and HTML imports, vertical and horizontal writing, background media, a table of contents, saved reading positions, and HTML export.

Each language edition is fixed to its interface language and includes a default text in that language.

## Download

[Download Hitohira](https://github.com/z0w1non/Hitohira/raw/HEAD/public/hitohira-en.html?download=1)

Open the downloaded HTML file in a browser. No network connection is required while using the viewer.

## Ruby annotations

Use HTML such as `<ruby>漢字<rt>かんじ</rt></ruby>` to display an annotation. In TXT and Markdown, use `ruby`, `rt`, and `rp` tags without attributes. The Japanese interface also supports `｜今日《こんにち》` and `漢字《かんじ》`.
