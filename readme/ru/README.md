# Hitohira

Автономная программа для чтения романов, работающая из одного HTML-файла. Поддерживает импорт TXT, Markdown и HTML, вертикальное и горизонтальное письмо, фоновые изображения и видео, оглавление, сохранение позиции чтения и экспорт в HTML.

Интерфейс выбирает язык по настройкам браузера. Доступны японский, английский, упрощённый и традиционный китайский, испанский, французский, немецкий, португальский, корейский, русский, арабский и хинди.

## Руби-аннотации

Для аннотации используйте HTML, например `<ruby>текст<rt>аннотация</rt></ruby>`. В TXT и Markdown используйте теги `ruby`, `rt` и `rp` без атрибутов. Японский интерфейс также поддерживает `｜今日《こんにち》` и `漢字《かんじ》。
