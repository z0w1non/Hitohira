# Hitohira

HTML 파일 하나로 실행되는 독립형 소설 뷰어입니다. TXT, Markdown, HTML 파일 가져오기, 가로쓰기와 세로쓰기, 배경 이미지 및 동영상, 목차, 읽던 위치 저장, HTML 내보내기를 지원합니다.

화면 언어는 브라우저의 기본 설정을 따르며 일본어, 영어, 중국어(간체·번체), 스페인어, 프랑스어, 독일어, 포르투갈어, 한국어, 러시아어, 아랍어, 힌디어를 지원합니다.

## 루비 주석

`<ruby>본문<rt>주석</rt></ruby>`과 같은 HTML로 주석을 표시하세요. TXT와 Markdown에서는 속성이 없는 `ruby`, `rt`, `rp` 태그를 사용합니다. 일본어 인터페이스는 `｜今日《こんにち》`와 `漢字《かんじ》`도 지원합니다.
