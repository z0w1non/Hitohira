# Hitohira

Un lector de novelas independiente que funciona desde un único archivo HTML. Permite importar archivos TXT, Markdown y HTML, leer en vertical u horizontal, usar imágenes o vídeos como fondo, consultar un índice, guardar la posición de lectura y exportar a HTML.

La interfaz sigue el idioma preferido del navegador y está disponible en japonés, inglés, chino simplificado y tradicional, español, francés, alemán, portugués, coreano, ruso, árabe e hindi.

## Descarga

[Descargar Hitohira](https://github.com/z0w1non/Hitohira/raw/HEAD/public/hitohira-es.html?download=1)

Abre el archivo HTML descargado en un navegador. No se necesita conexión a Internet para usar el visor.

## Anotaciones ruby

Usa HTML como `<ruby>base<rt>anotación</rt></ruby>` para mostrar una anotación. En TXT y Markdown, escribe las etiquetas `ruby`, `rt` y `rp` sin atributos. La interfaz japonesa también admite `｜今日《こんにち》` y `漢字《かんじ》`.
