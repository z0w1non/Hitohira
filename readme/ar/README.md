# Hitohira

قارئ مستقل للروايات يعمل من ملف HTML واحد. يدعم استيراد ملفات TXT وMarkdown وHTML، والكتابة العمودية والأفقية، واستخدام الصور أو الفيديو كخلفية، وعرض الفهرس، وحفظ موضع القراءة، والتصدير إلى HTML.

تتبع الواجهة اللغة المفضلة في المتصفح، وتتوفر باليابانية والإنجليزية والصينية المبسطة والتقليدية والإسبانية والفرنسية والألمانية والبرتغالية والكورية والروسية والعربية والهندية.

## التنزيل

[تنزيل Hitohira](https://github.com/z0w1non/Hitohira/raw/HEAD/public/hitohira-ar.html?download=1)

افتح ملف HTML الذي تم تنزيله في المتصفح. لا يلزم الاتصال بالإنترنت لاستخدام القارئ.

## شروح روبي

استخدم HTML مثل `<ruby>النص<rt>الشرح</rt></ruby>` لعرض شرح. في ملفات TXT وMarkdown، استخدم وسوم `ruby` و`rt` و`rp` دون سمات. تدعم الواجهة اليابانية أيضًا `｜今日《こんにち》` و`漢字《かんじ》`.
