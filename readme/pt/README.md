# Hitohira

Um leitor de romances independente que funciona em um único arquivo HTML. Permite importar arquivos TXT, Markdown e HTML, ler na vertical ou na horizontal, usar imagens ou vídeos como plano de fundo, consultar um índice, salvar a posição de leitura e exportar para HTML.

A interface segue o idioma preferido do navegador e está disponível em japonês, inglês, chinês simplificado e tradicional, espanhol, francês, alemão, português, coreano, russo, árabe e hindi.

## Download

[Baixar Hitohira](https://github.com/z0w1non/Hitohira/raw/HEAD/public/hitohira-pt.html?download=1)

Abra o arquivo HTML baixado em um navegador. Não é necessária conexão com a Internet para usar o leitor.

## Anotações ruby

Use HTML como `<ruby>texto<rt>anotação</rt></ruby>` para exibir uma anotação. Em TXT e Markdown, use as tags `ruby`, `rt` e `rp` sem atributos. A interface japonesa também aceita `｜今日《こんにち》` e `漢字《かんじ》。
