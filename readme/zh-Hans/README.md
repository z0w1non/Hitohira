# Hitohira

一款独立的小说阅读器，可通过单个 HTML 文件运行。支持导入 TXT、Markdown 和 HTML 文件，横排或竖排阅读，设置背景图片或视频，查看目录，保存阅读位置，以及导出为 HTML。

界面会跟随浏览器的首选语言，支持日语、英语、简体中文、繁体中文、西班牙语、法语、德语、葡萄牙语、韩语、俄语、阿拉伯语和印地语。

## 下载

[下载 Hitohira](https://github.com/z0w1non/Hitohira/raw/HEAD/public/hitohira-zh-cn.html?download=1)

在浏览器中打开下载的 HTML 文件即可。使用阅读器时无需连接网络。

## 注音

使用 `<ruby>正文<rt>注音</rt></ruby>` 这样的 HTML 添加注音。TXT 和 Markdown 中请使用不带属性的 `ruby`、`rt`、`rp` 标签。日语界面还支持 `｜今日《こんにち》` 和 `漢字《かんじ》`。
