# Hitohira

Un lecteur de romans autonome qui fonctionne à partir d’un seul fichier HTML. Il permet d’importer des fichiers TXT, Markdown et HTML, de lire à la verticale ou à l’horizontale, d’utiliser une image ou une vidéo en arrière-plan, de consulter une table des matières, d’enregistrer la position de lecture et d’exporter en HTML.

L’interface suit la langue préférée du navigateur et est disponible en japonais, anglais, chinois simplifié et traditionnel, espagnol, français, allemand, portugais, coréen, russe, arabe et hindi.

## Téléchargement

[Télécharger Hitohira](https://github.com/z0w1non/Hitohira/raw/HEAD/public/hitohira-fr.html?download=1)

Ouvrez le fichier HTML téléchargé dans un navigateur. Aucune connexion Internet n’est nécessaire pour utiliser le lecteur.

## Annotations ruby

Utilisez du HTML comme `<ruby>base<rt>annotation</rt></ruby>` pour afficher une annotation. Dans les fichiers TXT et Markdown, utilisez les balises `ruby`, `rt` et `rp` sans attributs. L’interface japonaise accepte aussi `｜今日《こんにち》` et `漢字《かんじ》。
