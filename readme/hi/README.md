# Hitohira

एक स्वतंत्र उपन्यास रीडर, जो एक ही HTML फ़ाइल से चलता है। इसमें TXT, Markdown और HTML फ़ाइलें आयात करना, क्षैतिज और ऊर्ध्वाधर लेखन, पृष्ठभूमि चित्र और वीडियो, विषय-सूची, पढ़ने की स्थिति सहेजना और HTML निर्यात करना शामिल है।

इंटरफ़ेस ब्राउज़र की पसंदीदा भाषा के अनुसार बदलता है। जापानी, अंग्रेज़ी, सरलीकृत और पारंपरिक चीनी, स्पेनिश, फ़्रेंच, जर्मन, पुर्तगाली, कोरियाई, रूसी, अरबी और हिंदी उपलब्ध हैं।

## डाउनलोड

डाउनलोड की गई HTML फ़ाइल को ब्राउज़र में खोलें। रीडर का उपयोग करने के लिए इंटरनेट कनेक्शन की आवश्यकता नहीं है।

## रूबी टिप्पणियाँ

टिप्पणी दिखाने के लिए `<ruby>पाठ<rt>टिप्पणी</rt></ruby>` जैसा HTML उपयोग करें। TXT और Markdown में `ruby`, `rt`, `rp` टैग बिना attributes के उपयोग करें। जापानी इंटरफ़ेस `｜今日《こんにち》` और `漢字《かんじ》` भी स्वीकार करता है।
