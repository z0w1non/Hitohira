无需外部服务器或库，打开一个 HTML 文件即可阅读小说。

阅读小说

从设置中导入 TXT、Markdown 或 HTML 文件，也可将文件拖放到页面。导入内容会先转换为安全的 HTML 再显示。

Markdown 标题、表格、列表、引用和代码块均受支持。请使用 <ruby>正文<rt>注音</rt></ruby> 这样的 HTML 标记添加注音。

调整显示与背景

可调整书写方向、字体、字号、行距和字距、注音大小、正文宽度和留白、颜色以及浅色或深色主题。

可使用 PNG、APNG、JPEG、WebP、GIF、BMP、SVG 图片或浏览器支持的视频作为背景。拖动或触摸可移动背景，双击可恢复位置。

目录、搜索与键盘

可根据标题生成目录。使用搜索按钮或 Ctrl+F 查找标题和正文，再选择结果跳转。阅读时可保持结果列表打开。

阅读位置、设置、导入内容和源文件会保存在本地。点击正文可翻页。横排和竖排使用相应方向的方向键，也可使用 PageDown/PageUp、空格/Shift+空格和 Home/End。按 F1 查看快捷键，按 S 打开设置，按 O 打开目录。

保存与导出

导出的 HTML 会将正文、设置、背景媒体和所需源文件数据嵌入一个独立文件，无需外部文件或临时运行时 URL。

可分别导出导入的文本、图片和视频源文件，并保留原始字节。分享或导出含个人或机密信息的内容前，请先检查内容。
