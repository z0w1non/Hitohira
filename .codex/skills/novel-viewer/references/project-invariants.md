# プロジェクト固有の不変条件

## 保存

- 設定は`localStorage`のキー`hitohira_settings`に保存する。
- 設定変更は画面へ即時反映し、最後の変更から250 ms後に最新設定をLocalStorageへ保存する。保存状態を表示し、失敗を通知する。別タブ競合が検出された場合は再読み込みまで保存変更を止める。
- 本文は`hitohira_content`に保存する。
- 読書位置は`hitohira_position:<documentId>`に保存し、設定・本文から分離する。背景メディアの移動量はこの読書位置レコードに含める。
- しおりは`hitohira_bookmarks:<documentId>`に文書単位で保存し、エクスポートHTMLへ埋め込まない。本文の置換・本文元ファイルの削除・初期化では対象文書のしおりも削除する。
- 実行時メディアと読み込んだテキストは、IndexedDBデータベース`hitohira_media_db`のバージョン1、オブジェクトストア`background_media`、キー`current`と`current_text`を使用する。
- LocalStorageとIndexedDBをまたぐ保存では、LocalStorageの未完了マーカーとIndexedDBの再実行記録を使う。通常版の起動時は未完了記録を復旧してから設定・本文を読む。復旧に失敗した状態で部分保存値を表示しない。
- 初期化ボタンの状態は、初期化対象となる設定・本文・元ファイル情報を既定値と比較する。読書位置とスクロールだけの状態は除外する。

## エクスポート

エクスポートHTMLは単体で完結させる。埋め込みデータだけを復元元とし、エクスポート元ページのBlob URLや外部実行時ファイルに依存させない。個別エクスポート用の元メディアBlobを保持し、画像・動画データをエクスポートデータへ埋め込む。タイトルはHTMLに`<title>`があればそれを使い、なければ読み込んだテキストのstemを使う。元テキストを削除したら既定タイトルへ戻す。
- 埋め込みJSONの形式を変更するときはスキーマ版を更新し、版なし旧形式の読込と未知版の挙動をテストする。

## 入力とナビゲーション

- マークダウン形式のテキスト読み込みでは、見出し・テーブル・一般的なマークダウン記法を安全なHTML変換・サニタイズを通じて扱う。
- ダブルクリックによるテキスト選択はブラウザに任せ、ページ送りも選択解除もしない。通常の選択中も範囲を削除せず、ページ送りだけを抑止する。
- 横書き・縦書きの移動は書字方向に従う。矢印キーは直感的にスクロールし、Space/Shift+SpaceとPageDown/PageUpは前後のページへ移動し、Home/Endは本文の端へ移動する。キー入力直後はsmooth移動とし、押し続けている間はkeyupまたはウィンドウ離脱まで等速移動する。
- 合成クリック抑止のためのポインター移動距離によるドラッグ判定は追加しない。

## 設定とメディア

- 初期化は変更履歴ではなく現在値を比較し、初期化直後と設定変更後に無効状態を更新する。読書位置を理由に有効化しない。
- 背景の自動配色は表示したまま、寸法を取得できる画像が読み込まれるまで無効化する。動画と既定紙画像では無効化する。
- Wake Lockのステータスは`画面スリープを防止`の右隣に全角丸括弧で表示する。表示値は`（有効）`、`（待機中）`、`（取得失敗）`、`（利用不可）`とする。エクスポートHTMLへ設定を引き継がない。
- 背景動画はミュート・自動再生・ループ・インライン再生とし、エクスポート後も再生可能にする。
