# ノベルビューア固有スキル

`novel_viewer.html`、`docs/SPECIFICATION.md`、または関連アセットを変更するときに使用する。保存、エクスポート、入力処理、設定UIに関わる動作を変更する前に、[references/project-invariants.md](references/project-invariants.md)を読む。

## 作業手順

1. 編集前に既存実装と対応する仕様を確認する。
2. 単一HTML構成を維持し、実行時の動作、エクスポートHTMLの動作、仕様書の内容を一致させる。
3. 重複したイベント処理や保存処理ではなく、共通関数と正規の状態を優先する。現行動作に不要な互換経路や識別子は削除する。
4. 動作、用語、保存、キーボードショートカット、UI構造を変更したら仕様書も更新する。`AGENTS.md`には開発方針を、`docs/SPECIFICATION.md`には製品動作を記載する。
5. 編集後に`git diff --check`を実行し、古い用語や重複経路を検索する。

## 用語とUI

- `本文パネル`を一貫して使用し、設定ラベルは`本文パネル色`とする。
- 用語定義以外では`地の文`ではなく`文章`を使用する。
- 操作できないファイル名はラベルとして表示し、右側に操作アイコンを配置する。削除をダウンロード・エクスポートより左に置く。
- インラインSVGのピクトグラムは`currentColor`を使用し、シンプルかつミニマルにし、意味のあるアクセシブルなラベルを付ける。
- モーダルはドロワーと同じテーマ色を使用し、表示中は背景メディアの操作を遮断する。

## 変更時の原則

廃止済みの旧LocalStorage互換処理、ドラッグ後の合成クリック抑止規則、設定初期化判定への読書位置の参加を再導入しない。ユーザーに見える動作と仕様書を一体の変更として扱う。
